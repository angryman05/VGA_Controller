# VGA_Controller
An university project that I had to make for the **Digital Systems Design** class.
This project is designed for the Nexys A7 development board.
You can upload this project to your board and use.
##Utilisation manual
-Connect a VGA monitor to your FPGA board.
-Activate the first switch(most right) to make the display visibile.
-First and second switch are used to select the colors for the shape.
-Third and fourth siwtch are used to select the shapes.
-The fifth switch is used to enable shape movement.
-The shape is moved with the buttons that are on the right on the board.
-The button in the middle is used to reset the shape position.
-The LEDs that ore on the top of the buttons will indicate the state of which action you are doing.*(Ex: change shape,colour,enable display,enable movement).
